# Открытие вида

Используются предоставленные logo/2.png (знак) и logo/3.png (написание). Прозрачные внешние поля обрезаны, пиксели не перерисованы. Header объединяет исходные знак и написание; footer использует тот же компонент.

Контур арки раскрывается маской, затем появляется внутренняя часть с 123. Это два маскированных слоя одного настоящего PNG: новый знак или выдуманный вектор не создавался. Движение связано с открытием архитектурного проёма и знакомством с пространством.

Preloader: конечная native CSS timeline с предельным выходом около 1.45 s. Готовность window.load и document.fonts.ready включает короткое затухание примерно 300 ms; искусственное ожидание полного ролика отсутствует. Loader не перехватывает указатель и не блокирует страницу.

Hover / keyboard focus: контур 620 ms, цифры 250 ms с задержкой 180 ms. Нет bounce, glow и вращения. При prefers-reduced-motion — полный неподвижный знак и скрытый loader. Отдельный видеофайл для логотипа не нужен.
